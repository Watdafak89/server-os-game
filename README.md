# ServerOps Academy — เกมสื่อการสอนรายวิชาระบบปฏิบัติการเครื่องแม่ข่ายเบื้องต้น

สื่อการสอนแบบเกมเชิงโต้ตอบ (Interactive Educational Web Game) สำหรับรายวิชา **ระบบปฏิบัติการเครื่องแม่ข่ายเบื้องต้น (Introduction to Server Operating Systems)** ทำงานได้ทันทีบนเว็บเบราว์เซอร์โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เสริม (รองรับการใช้งานออฟไลน์ 100%)

## วิธีเปิดใช้งาน
1. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (Chrome, Edge, Firefox หรือ Safari)
2. หากใช้งานหน้าห้องเรียนผ่านโปรเจคเตอร์ สามารถกดปุ่ม **☀️/🌙** มุมขวาบนเพื่อสลับเป็นโหมดสีสว่างได้

## โครงสร้างโหมดการเรียนรู้ภายในเกม
1. **ภารกิจผู้ดูแลระบบ (Incident Command — 8 ด่าน 16 สถานการณ์จำลอง)**
   - สถาปัตยกรรม Client-Server & ฮาร์ดแวร์ Server (ECC RAM, Redundant PSU)
   - การกู้คืนบริการ Web Server ด้วย `systemctl`
   - ระบบเครือข่าย DHCP, Static IP และ DNS
   - Windows Server Active Directory (AD DS) และ Group Policy (GPO)
   - สิทธิ์การเข้าถึงไฟล์ Linux (`chmod`, Principle of Least Privilege)
   - การตั้งค่า Firewall (UFW) และ SSH Hardening
   - ระบบจัดเก็บข้อมูล RAID 0/1/5/10 และการตรวจพื้นที่ดิสก์ (`df -h`)
   - แผนสำรองข้อมูล 3-2-1 Backup Rule และชนิดการสำรองข้อมูล (Full / Incremental / Differential)
2. **ห้องปฏิบัติการ Linux Server CLI (Interactive Terminal — 8 แล็บ)**
   - พิมพ์คำสั่งจริงบน Terminal จำลอง เช่น `whoami`, `ip a`, `systemctl start nginx`, `df -h`, `chmod 600 secret.key`, `chmod 755 backup.sh`, `ufw allow 443`, `useradd student01`
   - มีปุ่มคำสั่งช่วยจำ, คำใบ้, ประวัติคำสั่ง (ปุ่มลูกศรขึ้น-ลง) และตรวจผลอัตโนมัติ
3. **Port & Service Rush (เกมจับคู่พอร์ตและโปรโตคอล)**
   - โหมดจับเวลา 60 วินาทีพร้อมระบบ Combo และโหมดฝึกซ้อมไม่จำกัดเวลา
   - ครอบคลุม 14 พอร์ตมาตรฐาน (21, 22, 23, 25, 53, 67/68, 80, 110, 123, 143, 443, 445, 3306, 3389)
4. **คลังความรู้ + เครื่องมือจำลอง (Server OS Codex)**
   - **เครื่องคำนวณสิทธิ์ CHMOD แบบโต้ตอบ** (คลิกเลือก r/w/x ดูค่าเลขฐานแปดทันที)
   - **แบบจำลองดิสก์ RAID 0 / 1 / 5 / 10** พร้อมตารางเปรียบเทียบความจุและความทนทาน
   - สรุปเนื้อหาบทเรียนครบ 5 หมวด
5. **แบบทดสอบวัดความรู้และเกียรติบัตร (Exam & Printable Certificate)**
   - สุ่มข้อสอบ 10 ข้อจากคลัง 15 ข้อ พร้อมเฉลยอธิบายละเอียดทุกข้อ
   - เมื่อสอบผ่าน 70% ขึ้นไป สามารถพิมพ์หรือบันทึก **เกียรติบัตรออนไลน์ (PDF)** ได้ทันที

## การปรับแต่งเนื้อหา / เพิ่มข้อสอบ
ผู้สอนสามารถแก้ไขโจทย์ภารกิจ, แล็บ CLI, รายการพอร์ต หรือเพิ่มข้อสอบในคลังได้โดยตรงที่ไฟล์ `data.js`
