☁️ Cloud Sync ข้ามอุปกรณ์ (Firebase Realtime Database)

วาง URL ของ Firebase RTDB แล้วกด ทดสอบ และ บันทึก & ซิงค์ เพื่อซิงค์คะแนนและ Leaderboard ข้ามทุกอุปกรณ์แบบเรียลไทม์!

🔗 ลิงก์ห้องเรียนสำหรับส่งให้นักศึกษา (เชื่อมต่อ Cloud อัตโนมัติ)
📖 วิธีสร้าง Firebase RTDB URL ฟรีใน 2 นาที (คลิกเพื่อดู)
  1. เข้า console.firebase.google.com ล็อกอิน Google แล้วกด Add project
  2. เมนูซ้ายเลือก Build → Realtime Database → Create Database (เลือกโซน Singapore asia-southeast1 และเลือก Start in test mode)
  3. คัดลอกลิงก์ URL ด้านบน (ลงท้ายด้วย .firebasedatabase.app) มาวางช่องด้านบน หรือวางถาวรในไฟล์ cloud-config.js
  4. ตั้งค่าแท็บ Rules ของ Firebase เป็น: 
    {
  "rules": {
    "serverops_accounts": { ".read": true, ".write": true },
    "serverops_healthcheck": { ".read": true, ".write": true }
  }
}
